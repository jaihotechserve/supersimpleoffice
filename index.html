    How to Download & Run on Windows

    No Python installation or administrator rights required.

    STEP 01

    Download Individual or Full ZIP

    Download a single app archive (~45 MB) or the complete FullSuite ZIP (695.83 MB) directly from GitHub Releases.

    STEP 02

    Extract the Folder First

    Right-click the downloaded .zip file and choose Extract All... so the executable stays alongside its bundled _internal and resources folders.

    STEP 03

    Launch & Verify Checksums

    Double-click JaihoOffice.exe or any individual app. If Windows SmartScreen prompts on first launch, click More info → Run anyway. Verify integrity anytime via SHA256SUMS.txt.

    Local-First Engineering Guarantees

    Designed for reliability, speed, and complete data ownership.

    01 / CRASH-SAFE STORAGE

    Atomic Writes + Auto Backups

    Every file save writes to a temporary file, flushes with fsync, rotates a timestamped backup in %LOCALAPPDATA%, and atomically replaces the target.

    02 / SQLITE WAL MODE

    Fast Local Databases

    Notes, tasks, calendar events, focus logs, and LAN chat histories persist in local SQLite Write-Ahead Logging databases for instant search and zero corruption.

    03 / SAME-NETWORK LAN CHAT

    Zero-Cloud Team Messaging

    SimpleChat uses salted PBKDF2-HMAC-SHA256 user login, subnet/network policy checks, 1-on-1 DMs, group rooms, voice clips, and file transfers strictly over your local network.

    04 / OPEN FILE FORMATS

    Standard Interoperability

    Work natively with standard .docx, .xlsx, .pptx, .pdf, .ics, .md, .csv, and .json files without lock-in.
